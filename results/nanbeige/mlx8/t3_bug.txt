```python
"""Tiny shopping-cart module with the bugs fixed."""

def line_total(price_pence: int, qty: int) -> int:
    return price_pence * qty

def apply_discount(total_pence: int, percent: int) -> int:
    """Percent off, rounded to the nearest penny (half rounds up)."""
    discount = (total_pence * percent + 50) // 100
    return total_pence - discount

def cart_total(items, discount_percent=0, free_shipping_over=5000, shipping=399):
    subtotal = sum(line_total(p, q) for p, q in items)
    total = apply_discount(subtotal, discount_percent)
    if total >= free_shipping_over:
        return total
    return total + shipping
```

Explanation of bugs fixed:

1. **Free-shipping boundary bug**  
   The original code used:

   ```python
   if total > free_shipping_over:
   ```

   This made spending exactly the threshold value still incur shipping. The test says spending exactly the threshold earns free shipping, so it should be:

   ```python
   if total >= free_shipping_over:
   ```

2. **Discount rounding bug**  
   The original discount calculation used floor division:

   ```python
   total_pence - (total_pence * percent) // 100
   ```

   That always rounds down. For example, `apply_discount(999, 15)` computed a discount of `149` instead of `150`.

   The fixed version rounds to the nearest penny, with halves rounding up, using integer arithmetic:

   ```python
   discount = (total_pence * percent + 50) // 100
   ```

   This makes `apply_discount(999, 15)` return `849` as required.
