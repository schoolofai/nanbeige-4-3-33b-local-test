```python
"""Tiny shopping-cart module."""

def line_total(price_pence: int, qty: int) -> int:
    return price_pence * qty

def apply_discount(total_pence: int, percent: int) -> int:
    """Percent off, rounded to the nearest penny (half rounds up)."""
    discount = (total_pence * percent + 50) // 100
    return total_pence - discount

def cart_total(items, discount_percent=0, free_shipping_over=5000, shipping=399):
    subtotal = sum(line_total(p, q) for p, q in items)
    total = apply_discount(subtotal, discount_percent)
    if total >= free_shipping_over:
        return total
    return total + shipping
```

**Bugs fixed**

1. **Discount rounding was wrong in `apply_discount`**
   - Original code:
     ```python
     total_pence - (total_pence * percent) // 100
     ```
   - This uses floor division, so the discount always rounds down.
   - For example, `apply_discount(999, 15)` calculates a discount of `149` instead of the required rounded value `150`.
   - Fixed by rounding the discount to the nearest penny with halves rounding up:
     ```python
     discount = (total_pence * percent + 50) // 100
     ```

2. **Free shipping boundary condition was wrong in `cart_total`**
   - Original code:
     ```python
     if total > free_shipping_over:
     ```
   - This charges shipping when the total is exactly equal to the free-shipping threshold.
   - The test comment says spending exactly the threshold earns free shipping, so the condition should be:
     ```python
     if total >= free_shipping_over:
     ```
